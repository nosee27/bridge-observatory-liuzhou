# 05 素材资源与许可

> 生成：2026-10-21 · 环境：Windows 11 / node v24.13.1
> 数据来源：调研代理工作转录中的实测记录（标注 **[实测-转录]**，含 GitHub API / npm registry / jsdelivr / md5 比对结果）与主会话复验（**[实测]**）；未能复核的标注 **[未验证]**。约束档位 b（+three MIT 示例模块）已由用户拍板为本项目当前主案。

## 结论摘要

1. three.js r180 仓库 LICENSE 为 MIT（1081B，© 2010-2025 three.js authors）[实测-转录]，**覆盖 examples/ 下全部代码与贴图**；单个文件无独立许可头（Water.js 实测无头）不构成障碍，保留 LICENSE 文件即满足义务。
2. vendor 主案的合规动作很轻：源码从 GitHub r180 tag 取（npm 包不含 examples 贴图 [实测-转录]），放进 `vendor/three-examples/` 附 README 注明来源 tag 与文件清单即可。
3. 唯一要留意的贴图是 Water.js 配套的 waternormals.jpg（248KB）：它与 jbouny/ocean（MIT）的资产逐字节相同（md5 一致 [实测-转录]），MIT 链路干净；但本项目优先用 canvas 程序化法线图替代，可零图片引入。
4. CC0 素材源（c 档对照）核实：Kenney City Kit 明确 CC0 [实测-转录]；Quaternius / Poly Pizza / ambientCG / Poly Haven 主流口径 CC0 但逐项标注未验证；Sketchfab 必须逐资产核对许可。
5. 引入任何 CC-BY 资产需在页面署名区加一行来源声明（模板见 §4）；**NC/ND 类许可与参赛场景冲突，一票否决**。

**vendor 单模块合规做法（b 档 SOP）**：
1. 从 `https://github.com/mrdoob/three.js/blob/r180/examples/jsm/...`（Raw 按钮）取文件，**锁定 r180 tag** 与 vendor/three 现有版本一致；
2. 放入 `vendor/three-examples/<objects|postprocessing|shaders|utils>/`，保持 examples 目录相对结构（模块间用相对路径 import，如 SMAAPass → SMAAShader）；
3. 写一个 `vendor/three-examples/README.md`：来源 tag（r180）、文件清单、日期、原仓库 LICENSE 位置；
4. `vendor/three/LICENSE` 已存在（M0 交付时附带）[实测：README 记载]，义务即已履行；MIT 不强制在页面展示署名。

## 3. CC0 素材源清单（c 档对照；本项目暂不引入）

| 来源 | 许可 | 典型资产 | 体积量级 | 风格匹配 | 状态 |
|---|---|---|---|---|---|
| Kenney（kenney.nl） | **CC0** [实测-转录] | City Kit (Commercial) 50 件城市构件 | 单包几 MB～几十 MB | 高（low-poly 标准件） | 已核实 |
| Quaternius | CC0（其官网/包内 LICENSE 逐包核对 [未验证]） | 建筑/自然/车辆打包 | 单包 5–30MB | 高 | 部分核实 |
| Poly Pizza | 聚合站，标 CC0 为主（**逐模型核对** [未验证]） | 单个 GLB | 单件 0.1–5MB | 中高 | 未逐项核实 |
| Sketchfab | 有 CC0 筛选器；**许可逐资产各异**，需登录下载 | 高低参差 | 单件 1–50MB | 参差 | 未核实（误标风险最高） |
| ambientCG | CC0 贴图站 [未验证-转录] | PBR 材质贴图 | 单套 10–100MB | 中（写实向，与 low-poly 混搭慎用） | 部分核实 |
| Poly Haven | CC0（资产+HDRI [未验证]） | HDRI/材质/模型 | HDRI 数十 MB | 高（HDRI 可做环境贴图） | 未核实 |

**「看似免费实则受限」的坑**：
- CC **BY**（须署名）、CC **BY-NC**（禁商用）、**BY-ND**（禁演绎）——后两者与参赛/分发冲突，直接排除；
- 聚合站（Poly Pizza/Sketchfab）的许可以**原资产页标注**为准，聚合标签可能过期；
- "Free" ≠ CC0：不少站免费下载但保留所有权利（All Rights Reserved），禁止再分发——本项目仓库要开源分发，**再分发权是硬条件**；
- CC0 也建议在 README 记一行来源（好习惯，零成本）。

## 4. 许可兼容风险表与署名写法

| 许可 | 已用于本项目 | 署名义务 | 参赛风险 | 动作 |
|---|---|---|---|---|
| ODbL 1.0（OSM 数据） | ✅ 在用 | **必须**页内署名 | 低 | 已做（index.html 右下 + geo.mjs 头）[实测] |
| MIT（three 及 examples） | ✅ 在用 / b 档扩用 | 保留 LICENSE 即可 | 极低 | vendor/examples 时补 README |
| CC0 | c 档可选 | 无强制 | 低 | README 记来源 |
| CC-BY 3.0/4.0 | 未用 | **必须**署名（作者名+许可+链接+改动说明） | 中（漏署名=侵权） | 引入时按下述模板加 |
| CC-BY-NC / ND | — | — | **高（禁商用/禁改）** | 一票否决，不引入 |

**CC-BY 署名模板**（加入 index.html 现有署名区即可）：

```text
第三方素材：[资产名] 作者 [作者名]，[CC BY 4.0]
（https://.../链接），有/未修改。
```

**b 档落地注意事项（checklist）**：
1. vendor 目录 `vendor/three-examples/` + README（tag r180、文件清单、日期）——见 §1 SOP；
2. 文件清单按需取，勿整目录拷贝：水面批 = Water.js（或零 vendor 方案①）；天空批 = Sky.js；后期批 = §2 的 12 文件 109.8KB；几何批 = BufferGeometryUtils.js；
3. **docs/原创性与知识产权说明.md 需要更新**：第 3 条现在写的是"未使用外部图片、字体文件或第三方运行代码"（README 同款表述）——b 档落地后改为"运行时代码使用 three.js 0.180.0（MIT）及其官方示例模块（MIT，清单见 vendor/three-examples/README.md）；页面无外部图片与字体，数据 ODbL 署名照旧"。参赛语境下这句话比"零第三方"更稳：代码许可清晰可查，不构成原创性质疑；
4. 每次新增 vendor 文件同步更新该说明与 README，保持"任意提交可答辩"。
