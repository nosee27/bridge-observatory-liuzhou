# 04 视觉升级技术（three.js 0.180）

> 生成：2026-10-21 · 环境：Windows 11 / git-bash / node v24.13.1 / three 0.180.0（vendor 本地实测）
> 数据来源说明：本报告由主会话在两任调研代理因 API 超时阵亡后接管完成。核心数据来自它们留下的工作转录（标注 **[实测-转录]**）与主会话对本项目源码的直接复验（标注 **[实测]**）；少数第三方经验值标注 **[未实测]**。所有 three.js API 适用性均对照 r180 源码核实。

## 结论摘要

1. 渲染器现状：`toneMapping` 为默认 **NoToneMapping**、exposure=1、输出 SRGB——上一轮 v1.8 提亮是在无色调映射下手调的；换 ACES 需整体联动，否则会复刻"一片黑"。
2. 水面是性价比最高的升级点：现有贴花平面加 **canvas 法线贴图双帧滚动**即可获得波光（零 vendor、S 级工作量）；three 官方 Water.js 可用但必须把噪声 size 调到 ≈137–275（官方默认参数在 1 单位=100m 尺度下河面几乎无波形），且需自备法线贴图。
3. Sky.js（7.3KB，无外部纹理）可替换现有渐变圆柱：物理散射太阳+暮霭，且可直接喂 PMREM 生成环境贴图（本地 vendor 已实测导出 PMREMGenerator）。
4. 后期链（EffectComposer+UnrealBloom+Output）vendor 总体积 **109.8KB [实测-转录]**、各模块只依赖 'three'；但第一优先级建议**先不上后期**——emissive+雾+精灵光晕能覆盖 80% 的 bloom 收益。
5. 材质升级走"参数表 + canvas 程序化贴图"路线，与全离线约束完全兼容。
6. 建议先做 5 件：①水面法线动画 ②材质参数表+窗户贴图 ③Sky.js 换装 ④ACES 色调映射（联动调参） ⑤默认机位构图+首次环绕运镜。

## 1. 水面升级（柳江是画面主角，优先投入）

柳江在取景窗口内是一条 3 单位（300m）宽、贯穿全场的连续条带（v2.0 后单层水面贴花）。1 单位=100m，这是所有波纹计算的换算基础。

### 方案对比

| 方案 | 原理 | 离线兼容 | 性能成本 | 视觉收益 | 工作量 |
|---|---|---|---|---|---|
| ① canvas 法线贴图动画 | 程序生成 512² 法线图，normalMap 双份不同速率滚动 | ✅ 全程序化 | 极低（每帧只改 texture.offset） | ★★★ 波光粼粼 | **S** |
| ② Water.js（vendor） | 官方 ShaderMaterial：法线扰动+太阳镜面耀斑+env 反射 | ✅ 需 vendor 12.9KB + 法线贴图（见下） | 中（单 pass shader） | ★★★★ | M |
| ③ 自写 ShaderMaterial 菲涅尔 | 在现有贴花上叠加 fresnel + env 反射 + 波光 | ✅ | 低 | ★★★ | M-L |
| ④ Gerstner 顶点波 | 顶点级几何波 | ✅ | **不适用**（见下） | — | — |

**④ 的否决理由 [计算]**：真实江面波幅 0.1–0.5m = 0.001–0.005 单位，而 420 距离下 24 位深度/视锥分辨率为 0.026 单位（计划书 v1.9 实测数据）——总览视角下几何波低于亚像素；要可见就得把波幅做到米级，100m/单位下就是"水墙"。且河道贴花条带顶点密度沿折线分布，加密细分浪费。**结论：细节只能做法线扰动（假细节），不做几何波。**

**② 的两个关键坑 [实测-转录]**：
1. **噪声尺度**：Water.js 的 `getNoise` 以 `worldPosition.xz * size` 采样、内除 103。官方 demo（10000 单位平面、size=1）波纹空间周期 ≈103 单位=10.3km。落到柳江 3 单位宽的河面：默认参数下河面只有 0.03 个周期——**一片死平**。要出 4–8 个波纹周期需 `size ≈ 137 / 206 / 275`（转录中逐值验算：repeats 4→137.3、6→206.0、8→274.7）。
2. **法线贴图必须自备**：Water.js 的 `waterNormals` 选项默认 null（实测源码），官方配套 waternormals.jpg（248KB，2013 年 Photoshop 制作，JPEG/EXIF [实测-转录]）在 npm 包里不存在（jsdelivr 路径 404 [实测-转录]），只能从 GitHub raw 取。合规性见 05 报告；**体积敏感的话用方案①的 canvas 法线图喂给它，零图片成本**。

**推荐组合**：
- **第一批（S）**：方案①。`makeWaterNormalTexture()` 生成 512² 法线（多组正弦波叠加再重映射到法线空间），两份贴图以 (0.010, 0.006) 与 (-0.007, 0.011)/s 异速滚动，normalScale 0.25–0.4。接入点：`atlas.mjs` 水面材质处 + 每帧 offset 更新（挂到现有渲染循环）。
- **第二批（M，可选）**：切到 Water.js（size≈180、sunDirection 与 theme.sunPosition 同步、法线用①生成的贴图），获得太阳耀斑 glitter。注意核实其 fog 集成选项（[未验证]：Water.js 是否支持 `fog: true`——r180 源码有此选项但转录未验证取值行为）。
- **Reflector（平面镜反射）不推荐全河道**：它要整场景额外渲染一遍（当前 169 网格 → 反射 pass 翻倍 draw calls，突破 300 预算 [实测-转录：网格数出自 v2.1]），仅可考虑给单桥态局部水面，暂缓。

## 2. 天空与氛围

### Sky.js（推荐 vendor，第二批）

- **体积与依赖 [实测-转录]**：`examples/jsm/objects/Sky.js` 7257B / 237 行，import 闭包只含 'three'，无任何外部纹理（Preetham 解析式散射在 shader 内计算）。
- **用法要点 [实测-转录]**：`turbidity`（默认 2）、`rayleigh`（1）、`mieCoefficient`（0.005）、`mieDirectionalG`（0.8）、`sunPosition`（Vector3）；Mesh 本体是 `BoxGeometry(1,1,1)` + BackSide，官方示例 scale=450000。落到本项目：scale 取值只需大于雾 far 与地面外扩半径（1700），取 4000–8000 即可（不必照抄 450000）；`sunPosition` 用 `theme.lights.sunPosition` 归一化 × 100 保持同源。
- **环境贴图联动**：本地 vendor 已实测导出 `PMREMGenerator` [实测-转录]。Sky 渲染到 PMREM → `scene.environment`，比现在的 canvas 渐变更真实，且和天空视觉完全一致（渐变圆柱方案里两者其实是"近似一致"）。
- **替换点**：scene.mjs `skyTexture()`（L66-99）整体替换，theme.mjs 的 sky 三色保留给"Sky 不可用时的降级"。

### 廉价光晕（第一批可做）

- 太阳精灵：径向渐变 canvas sprite + AdditiveBlending，钉在 sunPosition 方向、尺寸随镜头距离衰减；配合 Sky.js 时可省（Sky 自带太阳盘）。
- 雾维持线性 Fog：FogExp2 在 1700 单位外扩地面下过渡区间难以控制（[经验判断]，线性 Fog 的 near/far 显式可控性更强），不建议换。

### 黄昏/夜晚主题

theme.mjs night 结构已占位（ready:false）。具体启用放在最后（见 §6 附注），色值表待 Sky.js 接入后用 turbidity/rayleigh 低值 + 太阳低角度实测调整，**不要现在纸面定值**（v1.8 的教训：颜色必须整体联动调）。

## 3. 色调映射与色彩管理（第二批，需联动）

**0.180 默认链 [实测-转录]**：`NoToneMapping` + `exposure=1` + 输出 SRGB。`ACESFilmicToneMapping` 在 vendor 模块内可用。

- **收益**：高光滚降（太阳耀斑、夜窗 emissive 不再死白剪裁），全画面饱和度/对比更"电影感"，是"精致化"观感的最大单项杠杆。
- **副作用（关键）**：ACES 整体压暗压灰（中间调约 ×0.8 亮度、饱和度重排）。v1.8 是在 NoToneMapping 下把亮度从 0.9%–9.5% 拉回中间调的——**直接切 ACES 等于复刻"一片黑"回归**。必须整体联动：`toneMappingExposure` 提到 1.15–1.25 [未实测，需实机调] + 太阳强度从 1.65 上调约 10–20% + 雾色随动。
- **落地方式**：theme.mjs 加 `tonemapping: { mode: 'aces', exposure: 1.2 }`，scene.mjs 读它设置 renderer；与 Sky.js 水面升级同批上线并整体验收，禁止单独切。
