# 《桥见柳州》演示视频脚本

建议时长：2 分 30 秒至 3 分钟。

录制前请双击 `桥见柳州.exe`（免装 Node.js，直接开独立窗口），或运行 `start.bat`（需 Node.js 18+）以本地服务方式打开作品。直接双击 `index.html` 会进入二维完整版本，录不到三维场景。

## 00:00—00:15 问题引入

画面：三维城市总览由远及近推入，柳江在城中绕出的那道弯与五座桥依次进入画面。

旁白：

> 柳州被称为“桥梁博物馆”。但每天从桥上经过时，我们真的看见桥了吗？

## 00:15—00:40 项目介绍

画面：镜头拉高，五座桥沿江同框；叠加作品标题与核心功能。

旁白：

> “桥见柳州”是一套面向青少年的城市桥梁数字漫游与结构科普平台。它用真实的柳江地理数据搭起一座可以走进去的城市，再把五座代表性桥梁，一座一座推到眼前。

## 00:40—01:10 城市总览：桥为什么建在这里

操作：

1. 拖动视角，绕柳江那道弯转一圈，展示五座桥的实际位置与相互关系；
2. 依次点击柳江大桥、文惠桥、文昌大桥、白沙大桥、凤凰岭大桥，镜头逐座推进；
3. 滚轮放大某座桥所在的江段，展示它实际横跨的江面。

旁白：

> 地图不是装饰。这五座桥为什么分布在这里、彼此相隔多远、各自跨过什么样的江面，都能在场景里直接读出来。

## 01:10—01:50 走进一座桥：构件与传力

操作：

1. 点击文惠桥，镜头推进到单桥场景，右侧展开“资料词条”；
2. 点选拱肋、吊杆、桥面梁与拱座，资料词条同步滚动到该构件并给出职责；
3. 在左侧“实验词条”里播放力流：桥面 → 吊杆 → 拱肋 → 拱座（可手动逐步，也可自动播放）；
4. 点「分层拆解」，把结构一层层摊开。

旁白：

> 同一座桥，可以从整体看到局部。点开每个构件，理解它承担什么力；按下播放，看着荷载从桥面一路传向拱座。

## 01:50—02:15 实验词条：把荷载加上去

操作：

1. 拖动「车辆荷载」滑杆，桥面上方的挠度曲线随之下沉；
2. 读数与常驻徽标写明“挠度曲线放大 ×N · 教学示意”，指出这个倍数是按各桥真实挠度现算的；
3. 切换「受力配色」，同一座桥按受拉、受压、受弯分区着色，并展开图例。

旁白：

> 改变荷载，桥会给出回应。这里所有数值都是教学用的示意比例，画面上标着放大了多少倍——学生看见的是力怎么被结构一层层分走，而不是一个被当成真的下沉量。

## 02:15—02:35 资料词条：对比与答题

操作：

1. 在资料词条里展开「对比」，A 是当前这座桥，B 换成另一座，五行并排、差异行标黄；
2. 打开「答题」，连答 2 至 3 道题，展示即时对错判定、解析与进度条。

旁白：

> 同一张表里对比不同桥型的受力，再把结论放进题目里检验——你到底有没有真正看懂它的传力逻辑。

## 02:35—02:55 总结与价值

画面：镜头拉回城市总览，五座桥与江湾同框；叠加资料来源与作品标题。可顺带切一次 `?present=1` 投屏排版，展示大字号与键盘切桥。

旁白：

> 我们希望让城市成为一本可以亲手翻开的工程书。“桥见柳州”不只介绍城市地标，更希望青少年学会从生活现象走向结构原理。

## 制作备注（录制前核对）

- **必须走本地服务**：双击 `index.html` 只会进入二维完整版本，三维镜头拍不到。双击 `桥见柳州.exe` 即可（启动器自带静态服务并用 Edge/Chrome 开独立窗口）。
- **署名不要裁掉**：画面右下角常驻「地图数据 © OpenStreetMap contributors（ODbL 1.0）」。凡出现底图的镜头请保留该署名，这是 ODbL 的署名要求；后期裁切画面时注意不要切掉。投屏（`?present=1`）与自助（`?kiosk=1`）形态下该署名同样常驻。
- **镜头均已可录**：单桥构件点选、力流（手动/自动）、分层拆解、车辆荷载与挠度曲线、受力配色、串行对比、答题与进度记忆都已实现，不再需要“改录二维”的替代方案。
- **两种展示形态**：课堂投屏用 `?present=1`（大字号 + 键盘 ←/→ 或 1–5 切桥 + Esc 回总览）；展馆自助用 `?kiosk=1`（自动巡览城市总览与五座桥梁，触碰即接管，静置 45 秒复位继续）。
- **术语统一**：构件名称以页面为准（拱肋 / 吊杆 / 桥面梁 / 拱座）；统一写作“力流”，不要写成“受力流”。挠度部分务必带上放大倍数，不要说成“实测下沉”。
- **节奏控制**：每段操作不超过 4 次点击，单个画面停留不少于 3 秒，方便评委看清。
