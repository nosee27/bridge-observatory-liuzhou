# 原创性与知识产权说明

1. 本作品围绕柳州城市桥梁结构科普进行独立策划和制作。参赛提交的页面结构、交互流程、二维页面的 SVG 教学图形、三维场景与桥梁模型、说明文字、知识题和演示材料，均由团队自行设计、编写或整理完成。三维场景中的河道走向、桥梁位置与朝向、地形高程，由团队编写的程序化代码依据公开地理与高程数据生成，不是外部素材拼接或直接下载的成品模型。

2. 作品未抄袭、剽窃、套作、冒名或虚假申报，未将同一作品重复提交至其他参赛项目。

3. 桥梁名称、建成年份、桥型等事实信息参考页面所列公开资料。结构动画、受力演示与荷载实验属于面向教学的解释性简化模型，不代表工程计算结论，不能用于实际工程设计或安全评估。

4. 作品使用的第三方资源如下，均按其许可条款使用，并在页面或提交材料中署名：

   - **three.js 0.180.0**（三维渲染库，MIT 许可）：以官方构建文件形式内置在 `vendor/three/` 目录（`three.module.min.js` 与 `three.core.min.js`），许可文件随附，未做任何修改。
   - **OpenStreetMap 地图数据**（ODbL 1.0）：用于生成场景中的河道与桥梁地理底图。页面右下角常驻「地图数据 © OpenStreetMap contributors（ODbL 1.0）」署名，数据来源、许可与生成日期同时记录在 `app3d/geo.mjs` 文件头部。作品未分发原始数据集，仅随作品提供按 ODbL 1.0 条款使用的少量派生几何（简化后的河道折线与桥梁轮廓参数）。
   - **地形高程数据**（全球 SRTM / GMTED2010，courtesy of the U.S. Geological Survey；瓦片打包 Mapzen Joerd，MIT；经 AWS Open Data Terrain Tiles 分发）：用于生成场景中的地形与山体。SRTM 为美国政府作品，属公共领域，按数据方要求完成署名即可。页面右下角常驻「地形高程 SRTM / GMTED2010 courtesy of the U.S. Geological Survey」署名，来源与处理方式记录在 `app3d/terrain.mjs` 文件头部。作品未分发原始瓦片，仅随作品提供重采样、压平、量化后的高程网格（169×253 格，约 84 KB），且仅覆盖柳州取景范围。

5. 作品未使用外部图片、字体文件、音乐或视频素材。后续如增加此类素材，团队将逐项取得授权，并在提交材料中注明来源、授权方式与页面位置。
