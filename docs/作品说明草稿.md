3、作品简介

《桥见柳州——城市桥梁数字漫游与结构科普平台》以柳州“桥梁博物馆”的城市资源为切入点，面向中学生、教师与城市访客，把柳江与五座代表性桥梁（柳江大桥、文惠桥、文昌大桥、白沙大桥、凤凰岭大桥）组织成一条从城市尺度走向构件尺度的空间叙事。作品采用纯前端 Web 架构，以三维城市场景为入口：用户先在依据真实地理数据搭建的柳江河道与江岸地形（含喀斯特孤峰）上，看到五座桥在江上的实际位置与相互关系，理解“桥为什么建在这里”。点击任意一座桥，镜头推进到该桥的三维单桥场景，可自由旋转视角、拉近观察，点选桥面、主梁、拱肋、斜拉索、桥墩与基础，理解不同桥型的传力路径。点击之后，画面右侧展开该桥的“资料词条”，按概览、构件、观察、来源、对比、答题六个分区收纳这座桥的全部内容；左侧的“实验词条”则提供力流演示、车辆荷载与挠度曲线、受力配色与结构拆解，可随时收起成一条进度读数。观察由此延伸为动手实验、资料查阅与知识自测，作品以“入城—看桥—动手—测评”构成完整学习链路，把城市地标从静态介绍转化为可操作的工程知识，可服务物理与工程启蒙、学校课堂、科技馆与城市研学，具有较好的教育、文化与传播价值。同一套内容可分别用于课堂投屏演示、展馆自助体验与学生随身复习，不必为不同场合重复开发。作品同时保留完整的二维内容版本：当运行环境不支持三维渲染时，作品自动回落到二维页面，交互地图、构件讲解、跟随力流、结构拆解、荷载实验、桥型对比与知识挑战等功能仍然完整可用，保证任何环境下都能完成学习。

4、创意来源

柳州跨江桥梁数量多、桥型丰富，是学生身边可以直接观察的工程资源，但常规科普往往停留在桥名、年代与外观介绍，真正决定桥梁稳定性的结构原理被隐藏在图片和结论中。项目希望把城市本身当作一间开放的工程教室，核心创意是把“看一座桥”转化为“观察一条传力链”：通过目标引导、构件点选、力流高亮、结构拆解与参数调节，让梁桥的受弯、拱桥的受压、斜拉桥的受拉变得可见、可比较。为避免把“示意图”误读成“实测结果”，作品在关键处主动交代夸张倍数：车辆荷载驱动的挠度曲线画在桥面上方，并标注按各桥真实挠度现算的放大倍数（实测柳江大桥 ×780、文惠桥 ×3400、文昌大桥 ×1900、白沙大桥 ×1300、凤凰岭大桥 ×2400），同时保留“教学示意”字样。在三维版本中，这一思路进一步落到“空间”上——城市不是背景板，而是叙事骨架：柳江在市区绕出的那道弯，本身就是五座桥为何如此分布的原因。作品因此选择用真实地理数据搭建底图，让地形与桥位自己说话，再借逐桥推进的镜头，把注意点从“城市里的桥”收拢到“桥上的构件”，形成由远及近、由整体到局部的认知顺序。作品同时结合柳州桥梁文化与工程知识，使科普内容具有城市辨识度和可迁移的教学方法。

5、运行环境

作品为纯前端静态站点，基于 HTML5、CSS3 与原生 JavaScript（ES 模块）开发，三维部分使用内置的开源渲染库 three.js（MIT 许可）绘制；不依赖后端服务、数据库或在线接口，全程离线可用，无需安装、不写入注册表、不申请管理员权限，可直接放在 U 盘或机房共享目录中运行。

桌面端（主要形态）：解压后双击 `桥见柳州.exe` 即可。这个约 11 KB 的启动器自带静态服务，会自动挑选可用端口（从 4173 起）、拉起本地页面，并以**独立应用窗口**（无地址栏、无标签页）直接进入三维城市总览；关闭窗口即退出，不在后台驻留。它**不需要预装 Node.js 或任何其他运行时**，只借用系统中已安装的 Microsoft Edge 或 Google Chrome 来承载窗口。若本机已装二者之一，也可直接双击 `start.bat`（需 Node.js 18+）或用命令行 `node server.js`，再用浏览器访问 http://127.0.0.1:4173。推荐在 Windows 10/11 或常见 Linux 桌面环境下使用，屏幕分辨率建议 1366×768 以上，并确保已启用 WebGL；检测到三维渲染不可用时，作品会给出明确提示并自动切换到二维完整版本，不会黑屏。

浏览器直达：作品同时也是标准静态站点，可直接部署到任意静态托管（含校内服务器），通过网址访问而无需安装客户端，适合机房统一分发与课后复习。

课堂与展陈：作品提供两种面向公开展示的形态，与常规浏览共用同一套内容。在地址后加 `?present=1` 进入**投屏排版**——放大标题、按钮与正文，提高对比度，并支持键盘快速切桥（←/→ 逐桥移动、数字 1–5 直接跳转、Esc 回总览）；加 `?kiosk=1` 进入**自助体验**——自动巡览城市总览与五座桥梁，观众一旦触碰即接管操作，停止操作约 45 秒后自动复位并继续巡览，适合科技馆、校园开放日与研学现场。

移动端：作品以两种方式在手机上使用。① 同一 Wi-Fi 直连——电脑上双击 `start-mobile.bat`（等价于启动器带 `--lan`；无启动器时退回 `node server.js --lan`），弹出的窗口会显示手机可输入的局域网地址（如 `http://192.168.47.92:4173`）。若手机提示无法访问，通常是 Windows 防火墙的入站规则未覆盖当前网络类型，双击 `允许手机访问.bat` 即可放行；也可运行 `node tools/lan-doctor.mjs` 一键自查（服务是否在跑、绑的是回环还是 `0.0.0.0`、防火墙规则是否覆盖、该抄哪个地址）。该模式仅绑定局域网、不影响桌面端，用完关闭窗口即恢复本机访问。② 静态托管——作品是纯静态站点，部署到任意静态托管后手机直接开网址，无需同一网络。二维内容完整适配 360—1440 像素宽度；三维场景在平板与手机上同样可用（单指拖动环视、双指捏合缩放，左右两个词条以底部抽屉呈现，可切换半屏与全屏）。检测到缺少 WebGL 或以本地文件方式直接打开时，作品自动回落到二维版本。

探索进度、答题成绩与新手引导状态保存在浏览器 localStorage 中，不使用账号、不上传任何数据。三维场景支持鼠标拖动任意角度环视、滚轮以光标所在位置为中心缩放、点击桥梁聚焦，右上角可一键复位。作品的全部交互状态都写在地址栏里（如 `#bridge/baisha?exp=1&step=2&load=0.5`），刷新、收藏与分享都能回到同一画面、同一次实验。
