# 桥见柳州

面向青少年的城市桥梁数字漫游与结构科普平台。项目选取柳江大桥、文惠桥、文昌大桥、白沙大桥和凤凰岭大桥，通过互动地图、结构构件讲解、车辆荷载演示和知识问答，帮助用户理解桥梁如何传力。

![桥见柳州首页](docs/previews/01-首页.png)

## 项目定位

作品将柳州的城市桥梁资源转化为可操作的工程学习材料。用户不只查看桥梁名称与年代，还可以选择构件、跟随力流、拆解结构、调节荷载，并通过桥型对比和知识挑战形成完整学习闭环。

## 核心体验

三维入口只有一处：打开即进入柳江城市总览，点击任意一座桥进入单桥视图，**左栏实验词条、右栏资料词条**。

- **沿江识桥**：五座代表性桥梁组成一条时间与结构路线，位置来自真实 OpenStreetMap 数据。
- **资料词条（右栏，常驻）**：概览 / 构件 / 观察 / 来源 / 对比 / 答题 六个分区，顶部吸顶导航一键跳转；构件行可点选，场景里点构件也会反查到这里。
- **实验词条（左栏，可收起）**：力流四步（手动步进或自动播放）、车辆荷载与挠度曲线、受力配色与图例、分层拆解；收起后保留一条进度读数。
- **荷载实验**：拖动荷载时桥面上方的挠度曲线随之起伏，倍数按各桥真实挠度现算并在三处明示（如“挠度曲线放大 ×780 · 教学示意”；五座桥现算得 ×780–×3400）。
- **桥型对比**：A 为当前桥、B 可切换，五行并排、差异行标黄，镜头可分别飞过去。
- **答题**：六道概念题，即时判对错、展开解析，进度写入 localStorage。
- **可分享状态**：`#bridge/baisha?exp=1&step=2&load=0.5&colors=1&explode=1`，刷新与前进后退都能复原。

## 本地运行

**推荐：双击 `桥见柳州.exe`**（约 11 KB）。它自带静态服务（自动挑端口，从 4173 起），用系统已装的 Edge 或 Chrome 以 `--app` 模式打开**独立窗口**（无地址栏、无标签页），关闭窗口即退出；不需要预装 Node.js。

重新编译启动器（用 Windows 自带的 .NET Framework `csc`，不下载任何东西）：

```powershell
node tools/build-launcher.mjs
```

也可以双击 `start.bat`（需 Node.js 18+），它会启动本地服务并打开浏览器首页。

## 手机上怎么打开

手机不能访问电脑的 `127.0.0.1`，所以默认模式只绑本机、手机打不开。要让手机/平板打开，有两种方式：

**方式一：同一 Wi-Fi（课堂、家里最省事）**

1. 电脑与手机连同一个 Wi-Fi；
2. 电脑上双击 **`start-mobile.bat`**（= 启动器带 `--lan`；没有启动器时自动退回 `node server.js --lan`）；
3. 会弹出窗口显示手机可输入的地址，形如 `http://192.168.47.92:4173`；
4. 手机浏览器输入该地址。

**如果手机显示"无法访问"，按这个顺序排查：**

| 现象 | 原因 | 处理 |
|---|---|---|
| 连不上、端口不通 | 启动时没带 `--lan`（默认只绑 `127.0.0.1`，手机永远连不上） | 用 `start-mobile.bat` 启动，不要直接双击 exe |
| 电脑自己能开、手机不行（多数情况） | Windows 防火墙入站规则只覆盖 Public，而家里 Wi-Fi 是 Private | 双击 **`允许手机访问.bat`**（会弹管理员授权），再重启一次 `start-mobile.bat` |
| 地址抄错 / 端口被占 | 另有服务占着 4173，启动器改了端口 | 看弹窗里的端口，别用手写的 4173 |
| 以上都对仍不行 | 路由器 / 校园网的「设备隔离」(AP isolation) | 换手机开热点、电脑连热点通常立刻可用 |

**一键自查：** 在项目目录运行

```powershell
node tools/lan-doctor.mjs
```

它会报告：服务是否在跑、绑的是回环还是 `0.0.0.0`、防火墙规则是否覆盖当前网络类型、以及手机该抄哪个地址。

注意：
- LAN 模式下整个项目目录对同网段可见，演示结束关掉窗口即恢复；
- `允许手机访问.bat` 只添加三条入站放行规则（node.exe / 启动器 / TCP 4173-4212），脚本里附了撤销命令。

**方式二：静态托管（无需同一网络）**

作品是纯静态站点，可直接部署到任意静态托管（GitHub Pages、校内服务器等），手机打开网址即可，与桌面端内容完全一致。

移动端体验：二维完整适配；三维同样可用——单指拖动环视、双指捏合缩放、左右两个词条为底部抽屉（可切换半屏 / 全屏）。

也可以在项目目录运行本地服务：

```powershell
node server.js
```

然后访问 `http://127.0.0.1:4173`。

也可以使用 Python：

```powershell
python -m http.server 4173
```

推荐使用最新版Microsoft Edge或Google Chrome浏览器。核心功能可离线运行，不依赖数据库、后端服务或第三方运行库。

## 技术实现

- 原生HTML、CSS和JavaScript
- 五种交互式SVG桥梁结构模型
- CSS 3D视角旋转
- Pointer Events拖动交互
- localStorage探索记录
- 响应式布局，已验证360—1440像素宽度
- 首次使用引导与键盘可操作的视角控制

## 文件说明

- `index.html`：页面结构与科普内容入口
- `styles.css`：视觉系统、响应式布局和动效
- `app.js`：桥梁数据、SVG结构模型、互动逻辑和知识问答
- `server.js`：零依赖本地静态服务器
- `桥见柳州.exe`：免安装启动器（内置静态服务 + Edge/Chrome 独立窗口，不需要 Node.js）
- `tools/build-launcher.mjs`：重新编译启动器
- `start.bat`：Windows 一键打开入口（需 Node.js 18+）
- `presentation/build-deck.js`：12页路演PPT生成脚本
- `docs/previews/`：网页与交互功能预览图
