# 桥见柳州

面向青少年的城市桥梁数字漫游与结构科普平台。项目选取柳江大桥、文惠桥、文昌大桥、白沙大桥和凤凰岭大桥，通过互动地图、结构构件讲解、车辆荷载演示和知识问答，帮助用户理解桥梁如何传力。

![桥见柳州首页](docs/previews/01-首页.png)

## 项目定位

作品将柳州的城市桥梁资源转化为可操作的工程学习材料。用户不只查看桥梁名称与年代，还可以选择构件、跟随力流、拆解结构、调节荷载，并通过桥型对比和知识挑战形成完整学习闭环。

## 核心体验

三维入口只有一处：打开即进入柳江城市总览，点击任意一座桥进入单桥视图，**左栏实验词条、右栏资料词条**。

- **沿江识桥**：五座代表性桥梁组成一条时间与结构路线，位置来自真实 OpenStreetMap 数据。
- **资料词条（右栏，常驻）**：概览 / 构件 / 观察 / 来源 / 对比 / 答题 六个分区，顶部吸顶导航一键跳转；构件行可点选，场景里点构件也会反查到这里。
- **实验词条（左栏，可收起）**：力流四步（手动步进或自动播放）、车辆荷载与挠度曲线、受力配色与图例、分层拆解；收起后保留一条进度读数。
- **荷载实验**：拖动荷载时桥面上方的挠度曲线随之起伏，倍数按各桥真实挠度现算并在三处明示（如“挠度曲线放大 ×780 · 教学示意”；五座桥现算得 ×780–×3400）。
- **桥型对比**：A 为当前桥、B 可切换，五行并排、差异行标黄，镜头可分别飞过去。
- **答题**：六道概念题，即时判对错、展开解析，进度写入 localStorage。
- **可分享状态**：`#bridge/baisha?exp=1&step=2&load=0.5&colors=1&explode=1`，刷新与前进后退都能复原。

## 三种交付形态

| 形态 | 入口 | 说明 |
|---|---|---|
| 常规浏览 | 直接打开 | 鼠标拖动环视、滚轮以光标为中心缩放、键盘方向键/WASD/± 控制镜头 |
| 课堂投屏 | `?present=1` | 放大字号与按钮、提高对比度；键盘 ←/→ 逐桥、数字 1–5 直跳、Esc 回总览 |

## 启动方式

### 推荐：用 Node.js 启动（两个 .bat）

评审与演示建议走这条路径——纯源码运行，**不涉及未签名 exe**，不会出现 SmartScreen 提示。

| 脚本 | 作用 | 绑定范围 |
|---|---|---|
| **`start-local.bat`** | 本机启动，自动打开浏览器 | 只有 `127.0.0.1`（手机连不上） |
| **`start-lan.bat`** | 对局域网开放，窗口里打印手机可用的地址 | `0.0.0.0`（手机可访问） |

两个脚本都会先检查 `node` 是否存在，缺 Node 时给出明确提示而不是一闪而过。需要 Node.js 18+（<https://nodejs.org>）。

等价命令：

```powershell
node server.js          # 本机
node server.js --lan    # 开放局域网（会打印手机地址）
```

### 备选：免装 Node 的两个 exe

机器上装不了 Node 时使用。两个 exe **互不干扰**，双击即用：

| 程序 | 绑定范围 | 双击后会发生什么 | 适合 |
|---|---|---|---|
| **`桥见柳州.exe`**（本地版） | 只有 `127.0.0.1` | 直接在本机打开独立窗口；**不开放局域网、不修改防火墙** | 自己看、课堂投屏 |
| **`桥见柳州-手机访问.exe`**（局域网版） | `0.0.0.0` | 只弹一个小窗口列出手机地址（带「复制地址」）；**不在本机打开画面**；关闭该窗口即停止服务 | 让手机 / 平板访问 |

两个程序都由同一份 `launcher/Program.cs` 编译而来（`LAN_EDITION` 编译期分叉），不需要预装 Node.js，关闭窗口即停止服务，不在后台驻留。

- 每次启动都会用独立的临时浏览器配置目录（`%TEMP%\qiaojian-liuzhou-app-<进程号>`），退出时删除——不会与上一次的浏览器窗口抢配置锁。
- 局域网版**启动时不会弹任何授权窗口**：只读取防火墙状态。若手机连不上、窗口提示“防火墙尚未放行”，点窗口里的 **「放行防火墙」** 按钮才会申请一次管理员权限（`Bridge Observatory (lan)` 与 `TCP 4173-4212`）。

重新编译两个 exe（Windows 自带 .NET Framework `csc`，不下载任何东西）：

```powershell
node tools/build-launcher.mjs
```

## 首次运行的安全提示

两个 exe **没有数字签名**，所以可能出现 UAC「未知发布者」或 SmartScreen「Windows 已保护你的电脑」——这是未签名程序的正常现象，不是病毒告警。

**想完全避开这些提示**：走推荐路径 `start-local.bat` / `start-lan.bat`（用 Node 运行源码，不涉及 exe），或在本机执行 `node tools/build-launcher.mjs` 重新编译一份本地 exe。

三种处理办法（详见 [docs/security-and-signing.md](docs/security-and-signing.md)）：

1. **就地编译**（零成本，评委演示最稳）：`node tools/build-launcher.mjs` —— 本地生成的 exe 不带「来自网络」标记，通常不再触发提示；
2. **解除锁定**：下载来的 ZIP 先执行 `Get-ChildItem *.exe | Unblock-File`；
3. **签名**：OV 证书可去掉「未知发布者」，EV 证书或 Azure Trusted Signing 可同时获得 SmartScreen 信誉。

文档里还附了两个 exe 的 SHA-256、三种提示的区别，以及本作品为「少触发系统提示」做的设计（启动不提权、只在点按钮时加一条防火墙规则、不联网、不驻留）。

## 手机上怎么打开

**推荐双击 `start-lan.bat`**（用 Node 开放局域网，窗口里会打印手机可用的地址）；机器上装不了 Node 时，双击 `桥见柳州-手机访问.exe`（弹窗显示同样的地址，带复制按钮）。手机连同一个 Wi-Fi，输入该地址即可。

**如果手机打不开，按顺序排查：**

| 现象 | 原因 | 处理 |
|---|---|---|
| 连不上，但电脑上能开 | 用的是本机模式（`start-local.bat` 或本地版 exe，只绑 `127.0.0.1`） | 换成 `start-lan.bat` 或 `桥见柳州-手机访问.exe` |
| 手机提示无法访问、窗口红字提示 | 防火墙尚未放行 | 点地址窗口里的「放行防火墙」按钮 |
| 地址连不上 | 电脑换了网络，IP 变了 | 用窗口里当前显示的地址 |
| 以上都对仍不行 | 路由器 / 校园网的设备隔离，或电脑连的是**手机热点** | 换普通路由器 Wi-Fi；或改用静态托管 |

**兜底：静态托管。** 作品是纯静态站点，部署到任意静态托管（GitHub Pages、校内服务器）后手机直接开网址，与网络环境无关。

**自查工具：** `node tools/lan-doctor.mjs` 会报告服务是否在跑、绑的是回环还是 `0.0.0.0`、防火墙规则是否覆盖当前网络类型、该抄哪个地址。

移动端体验：二维完整适配；三维同样可用——单指拖动环视、双指捏合缩放，左右两个词条为底部抽屉（可切换半屏 / 全屏）。

## 深链接

可以直接分享指定桥梁、显示模式和拆解状态：

```text
http://127.0.0.1:4173/#bridge/wenhui
http://127.0.0.1:4173/#bridge/baisha?exp=1&step=2&load=0.5&colors=1&explode=1
http://127.0.0.1:4173/?present=1     课堂投屏排版
http://127.0.0.1:4173/?kiosk=1       展馆自助巡览
```

旧格式 `#bridge=wenhui&mode=force&explode=1` 仍可解析并自动迁移到新地址，早期分享的链接不会失效。

## 技术实现

- 纯前端：原生 HTML / CSS / ES Module，零构建、零后端
- 三维：three.js 0.180.0（MIT，已 vendored 到 `vendor/three`），WebGL 2
- 地理：柳江河道与江岸地形来自 OpenStreetMap（ODbL 1.0）+ 高程数据，1 场景单位 = 100 米
- 五座桥按公开资料重建，构件级拾取（`partId` + 语义标签），高亮使用独立幽灵材质
- 二维版保留完整功能（交互地图、构件讲解、力流、拆解、荷载、对比、知识挑战），三维不可用时自动回退
- Pointer Events 拖动 + 滚轮锚点缩放 + 键盘镜头 + 触屏双指缩放
- 状态全部写进地址栏，可分享、可刷新、可前进后退
- localStorage：探索进度、答题记录、引导状态
- 响应式布局，已验证 360—1440 像素宽度；移动端两个词条为可拖拽抽屉
- `node tests/atlas.test.mjs`：**257 条自动断言**（几何间距、结构高度、数据一致性、交互接线、挠度换算恒等式、路由往返、面板渲染）

## 文件说明

**入口与启动**

- `start-local.bat`：**推荐**，用 Node 在本机启动（只绑 127.0.0.1）
- `start-lan.bat`：**推荐**，用 Node 开放局域网并打印手机地址
- `桥见柳州.exe`：本地版（免装 Node，只绑 127.0.0.1，本机独立窗口）
- `桥见柳州-手机访问.exe`：局域网版（免装 Node，绑 0.0.0.0，只弹地址窗口）
- `launcher/Program.cs` + `tools/build-launcher.mjs`：两个 exe 的源码与编译脚本（`LAN_EDITION` 编译期分叉）
- `server.js`：零依赖静态服务器（`--lan` 开放局域网）
- `start.sh`：Linux / macOS 入口

**三维**

- `app3d/main.mjs`：外壳、路由、面板接线、投屏与自助形态
- `app3d/scene.mjs`：镜头、拾取、力流、挠度曲线、受力配色、拆解
- `app3d/atlas.mjs`：场景装配与五座桥的几何构建
- `app3d/panel.mjs` / `app3d/lab.mjs`：资料词条（六分区）与实验词条
- `app3d/state.mjs` / `app3d/show-mode.mjs`：地址栏状态、投屏与自助形态的纯逻辑
- `app3d/geo.mjs` / `app3d/terrain.mjs` / `app3d/deflection.mjs`：地理数据、地形、挠度换算（纯函数）

**二维与素材**

- `index.html` / `styles.css` / `app.js`：二维完整版本（三维不可用时的回落）
- `presentation/build-deck.js`：12 页路演 PPT 生成脚本
- `docs/previews/`：预览图；`preview/`：五座桥的离屏渲染图

**工具**

- `tools/lan-doctor.mjs`：手机连不上时的一键自查
- `tools/render-preview.mjs`：导出桥梁预览图
- `tools/build-geo.mjs` / `tools/build-bridge-data.mjs`：从源数据生成模块（支持 `--check`）

## 答辩表述

“桥见柳州”将柳州“桥梁博物馆”的城市资源转化为可交互的工程教育内容。用户可以通过点击构件、跟随力流、调节荷载和比较桥型，直观看到桥面、主梁、拱肋、斜拉索、桥墩和基础之间的传力关系。

## 数据与版权说明

页面中的桥梁资料来自公开报道和科普资料，结构动画为教学简化模型，不用于工程计算。当前工程未使用外部图片、字体文件或第三方运行代码；页面预览图均为项目自身截图。
